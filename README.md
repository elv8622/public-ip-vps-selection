## 先把三个概念分开：公网IP、弹性IP、独立IP

### 公网IP 和弹性IP，差在“地址能不能单独管”

公网 IP 是互联网可路由的地址。VPS 绑定公网 IP 后，外部客户端可以通过这个地址访问你开放的服务，服务器也能通过它对外发起连接。但拥有公网 IP 不代表端口自动开放，也不代表带宽一定够：安全组、系统防火墙、服务监听地址、路由和端口配置，任何一环没对，外面都访问不进来。

弹性 IP 的重点在“地址可独立管理”。阿里云对 EIP 的官方定义是：独立的公网 IP 资源，可与 VPC 类型的 ECS、NAT 网关、ENI 网卡、私网负载均衡 SLB 绑定，并可以动态解绑；它和 ECS 固定公网 IP 的区别是支持专有网络、支持单独持有、支持弹性插拔、以网卡可见模式可见 IP。线路类型还分 BGP（多线）和 BGP（多线）精品线路，后者优化海外回中国内地的流量。

两者不是互斥关系。有的平台把实例直接绑定的固定公网地址叫公网 IP，有的把可迁移的公网地址单独叫 EIP，具体以平台产品定义为准。判断时别看名字，看三件事：

| 对比项 | 实例绑定公网 IP | 弹性 IP（常见定义） |
| --- | --- | --- |
| 地址与服务器关系 | 通常直接绑定某个实例或网卡 | 地址可作为独立资源管理，再绑定支持的云资源 |
| 是否可迁移 | 可能受实例生命周期或平台规则限制 | 常见能力是解绑后重新绑定，但目标资源和次数可能有限制 |
| 地址生命周期 | 可能随实例创建、释放或重建而变化 | 可能可在实例之外保留，是否持续收费需查平台规则 |
| 常见用途 | 单台服务器长期提供公网访问 | 故障切换、实例替换、迁移或需要固定出口地址 |
| 要核对的费用 | 公网带宽、流量、地址等费用 | 地址占用、带宽、流量、绑定状态等费用 |

如果你只是单台机器长期跑一个站点，实例自带公网 IP 往往够用；如果外部系统按来源 IP 给你开了白名单，换服务器时不想挨个通知对方改配置，才值得为“地址可独立保留、可重绑”多付钱。EIP 也不等于高可用：地址能切，不代表备用机有最新数据、应用能自动启动、数据库主备已同步。地址切换只解决入口，不解决业务本身。

### 独立IP 和共享IP，差在“邻居会不会连累你”

独立 IP 是这台 VPS 独享一个公网 IPv4，不和别人共用。共享 IP 则是多个用户共用一个出口，常见于 NAT VPS：商家把一个公网 IP 切给多个用户，每人分到一段转发端口，SSH、建站、跑代理都得在指定端口上折腾。

| 维度 | 独立IP | 共享IP |
| --- | --- | --- |
| 价格 | 偏贵 | 便宜 |
| 邻居影响 | 各管各的 | 同 IP 下别人被攻击、被封，你跟着倒霉 |
| SEO | 搜索引擎视为独立站点，更友好 | 可能因同 IP 站点被惩罚受牵连 |
| SSL | 可单独部署，配置灵活 | 通常用 SNI 共享证书 |
| 邮件发送 | IP 信誉独立，不易被连累 | 他人发垃圾邮件可能让整个 IP 进黑名单 |
| 直接 IP 访问 | 可以用 IP 直接访问站点 | 不行 |

临时测试环境用共享 IP 可以凑合。正式建站、做 SEO、跑外贸独立站、发邮件、对接支付接口，独立 IP 基本是刚需。跨境电商尤其如此：平台会把 IP 关联当成账号风险因素，省下来的那点钱，可能不够处理一次封号。

### “原生IP”要拆成两件事：注册归属和实际出口位置

市面上的“原生 IP”通常指 IP 注册地显示为目标地区，但注册归属和服务器实际出口位置是两件事。一家香港机房服务商在自家 FAQ 里把这话说得很直白：

> 因为全球 IPv4 紧缺，我们无法申请到很多 APNIC 的 IPv4 资源，所以可能向您分配 APNIC、RIPE、AFRINIC 等区域的 IPv4 地址，这是随机的，也不承诺切换到指定组织。但它们都被宣告到香港，位置更新为香港，速度上没有任何区别。

这段话说清楚了一个事实：IP 归属地显示不等于实际地理位置。普通建站、SEO 不用太在意；如果业务依赖对 IP 归属地做严格检测的平台，比如部分流媒体解锁、特定地区服务，买之前先实测或问客服，别只看商品页的“原生”两个字。

IP 干净度是另一回事。有的商家给 24 小时内发现黑名单问题的 IP 免费换一次，有的提供 48 小时无条件退款，这两种政策不是一回事：前者只换 IP，后者可以退整单。下单前问清楚适用条件和是否收费。

## 买之前要核对的 5 项

把下面五项逐条对一遍，比看十篇测评有用。

1. **地址生命周期**：实例停止、释放、重建或解绑后，IP 还在不在？未绑定时是否继续计费？有的平台对闲置 EIP 照样收费。
2. **能否迁移或重绑**：换服务器时要不要改 DNS、改白名单、改客户端配置？解绑和重绑有没有次数、地域、权限限制？
3. **带宽和流量**：入站和出站分别怎么算，流量是单向还是双向统计，超量是限速还是停机，峰值带宽是多少。地址类型不能说明带宽大小，两个同样标 100Mbps 的方案，计费方式可能完全不同。
4. **IP 干净度和更换政策**：新 IP 是否承诺不在黑名单，发现污染多久内能免费换，换 IP 收不收费。
5. **线路类型**：BGP 多线、CN2 GIA、CMI、AS9929 这些名词背后是回程路由和入向质量。有的商家会明确写“仅承诺出口，入向无承诺”，做反向代理、CDN 回源时要心里有数。

## IP 被封了怎么办

公网 IP VPS 用久了，IP 被封是绕不开的现实问题。行业里常见的处理路径有三种，以一家美国老牌商家公开的规则为例：

**迁机房，免费但有限制。** 每个机房分配的 IP 不一样，从 A 机房迁到 B 机房，相当于换了一个新 IP，不花钱、不限次数。前提是 IP 没有被封，且套餐支持多机房迁移。IP 一旦被封，系统会直接拒绝迁移。还要注意，从 A 迁到 B 再迁回 A，拿到的很可能还是原来那个 A 机房 IP，除非它已经被别人占用。

**付费换 IP，IP 被封后的主动方案。** 这家商家公开页面显示约 **$8.79/次**，换完承诺新 IP 全球可用、不在黑名单内，多数 30 分钟内完成，最多不超过 24 小时。价格会随时间调整，历史区间在 $2.82 到 $8.79 之间，以下单页为准。这是别家的价格，不是丽萨主机的报价，别混着看。

**部分高端套餐定期免费换。** 有的商家给 SLA 套餐每两周免费换一次 IP 的权益，普通套餐没有。买之前看清楚自己买的系列含不含这项。

换完 IP 不是结束。域名解析要改，防火墙 IP 白名单要加新地址，SSH 工具和代理客户端里的服务器地址也要同步更新，旧 IP 会被回收。想降低被封概率，社区里比较一致的经验是：流量行为尽量规律，别长期高并发冲击；换非标准端口；在 IP 被封之前定期迁机房更新地址，比被封之后花钱处理主动。

## FAQ

**公网IP VPS 和云服务器 ECS 有什么区别？**

VPS 和 ECS 都是虚拟化出来的服务器，功能上高度重叠。ECS 通常强调集群、镜像备份、快照和可用区，VPS 更常见于单台独立售卖、按月或按年付、配置和线路选择更灵活。对个人建站和中小业务来说，差别不在“能不能用”，而在故障恢复手段、计费方式和线路质量。别用云厂商贬低 VPS 的营销话术当事实。

**独立IP一定比共享IP快吗？**

不一定。速度看线路、带宽、回程优化和机房位置，独立 IP 解决的是“不被邻居连累”和“可以直接用 IP 访问”，不解决传输速度。一个共享 IP 的优质 CN2 线路，可能比一个独立 IP 的普通国际线路快得多。

**原生IP一定能在目标平台用吗？**

不一定。平台检测的不只是 IP 注册地，还包括 IP 段历史、欺诈分、浏览器指纹、账号行为等。原生 IP 只是降低门槛，不能保证过风控。买之前用试用机实测目标平台，比看商品页的解锁列表可靠。

**IP 被封了，等一段时间会自动解封吗？**

理论上会，但时间不可控。国内封锁的 IP 解封时间从几周到几个月不等，有的更长。如果 VPS 正在承载业务，等解封不现实，迁机房或付费换 IP 更实际。

**弹性IP 是不是就是公网IP？**

弹性 IP 是公网 IP 的一种管理方式，重点在“可独立持有、可解绑重绑”。有的平台把实例直接绑定的固定公网地址也叫公网 IP，有的把可迁移的地址单独叫 EIP。买的时候看三点：能不能单独保留、能不能重绑、地址和带宽流量分别怎么计费。
